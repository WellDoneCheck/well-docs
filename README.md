# 水井偵測系統

基於影像辨識技術識輔助定位水井位置

## 專案目標 
透過影像辨識AI分析空拍圖資，降低人工巡檢水井的時間與人力成本，並透過地圖化檢視協助管理。

## 核心功能概述

### 📊 辨識與審核流程
* **圖資上傳**：使用者上傳空拍圖（通常為大圖）。系統後端需設計**佇列/排隊機制**，以應對同時上傳一批大圖時的模型運算負載。
* **AI 自動偵測**：模型端自動分析空拍圖，偵測出所有疑似水井的位置並標記邊界框。
* **人工二次確認**：由水土人員線上審核，對辨識結果進行確認或刪除，確保進入地圖檢視的資料正確性。

### 🗺️ 地圖檢視
* **資料篩選**：地圖上**僅顯示「已審核且確認正確」**的水井標記，避免雜訊干擾。
* **資訊圖層**：點擊地圖標記可查看水井的詳細資訊（經緯度座標、水井類型、是否已合法登記等）。
* **進階功能**：後續考慮擴充分類篩選、區域統計等便利使用者查看的功能。

### 🔑 帳號與權限管理 
* **專屬限制**：本系統主要供水土保持相關人員內部使用。
* **一般使用者**：僅開放「登入」功能，不開放公開註冊。
* **系統管理員**：擁有最高權限，負責手動新增、管理其他工作人員的帳號。
